## Elements to evaluate

- Navigation Bar -> go from one page to another
- shopping cart -> add items to the shopping cart, view the shopping cart, remove items from the shopping cart
- profile page -> view profile information, edit profile information
- font size -> is the font size appropriate for the content? Is it easy to read?
- color scheme -> is the color scheme visually appealing? Does it provide enough contrast for readability?
- overall design -> is the overall design visually appealing? Does it provide a good user experience?

## Evaluation Questions

### Task 1 — Navigation discovery (Ready-to-buy → Blueprints)

From the starting page, open the navigation menu, go to the **Ready-to-buy** page, and then navigate to the **Blueprints** page.  
**Own testing time:** 8 seconds

**Questions**

1. **Ease of navigation:** How easy was it to complete this flow? (1–5)
2. **Time on task:** Approximately how long did it take? (seconds)
3. **Information clarity:** Were the page names and navigation labels clear and unambiguous? (1–5)
4. **Navigation quality:** How would you rate the navigation layout (placement, spacing, readability)? (1–5)
5. **Findability:** If you were looking for “Blueprints” again later, how confident are you that you could find it quickly? (1–5)
6. **Open feedback:** What, if anything, would you change about the navigation to make this flow faster or clearer? (short answer)

---

### Task 2 — Shopping flow (add two items, view cart, remove one)

Navigate to **Ready-to-buy**, add one item to the shopping cart, then navigate to **Blueprints** and add one blueprint. Open the **Shopping Cart** and remove **one** item.

**Own testing time:** \_\_\_ seconds

**Questions**

1. **Ease of checkout flow:** How easy was it to add two items from different sections and manage them in the cart? (1–5)
2. **Time on task:** Approximately how long did it take? (seconds)
3. **Add-to-cart clarity:** How clear was the “Add to cart” action (label, icon, placement, feedback)? (1–5)
4. **Feedback & system status:** Did you receive clear confirmation that items were added/removed? (1–5)
5. **Cart findability:** How easy was it to locate the cart from each page? (1–5)
6. **Cart usability:** How would you rate the cart UI (readability, item details, totals, controls)? (1–5)
7. **Error tolerance:** If you removed the wrong item, did it feel like you could recover easily (undo, clear messaging, simple re-add)? (1–5)
8. **Open feedback:** What was the most frustrating part of this flow, if any? (short answer)

---

### Task 3 — Profile management (view and edit)

Navigate to your **Profile** page, review your profile information, and update at least one field. Save your changes.

**Own testing time:** \_\_\_ seconds

**Questions**

1. **Findability:** How easy was it to find the profile area? (1–5)
2. **Time on task:** Approximately how long did it take? (seconds)
3. **Edit affordance clarity:** How clear was it where/how to edit your information? (1–5)
4. **Form usability:** How would you rate the editing experience (field labels, input behavior, validation, layout)? (1–5)
5. **Save confidence:** After saving, how confident were you that your changes were applied successfully? (1–5)
6. **Privacy & trust:** Did anything about the profile page make you unsure about privacy/security (e.g., unclear data use, too much exposed info)? (1–5)
7. **Open feedback:** What additional profile feature would you expect (change password, avatar upload, email preferences, etc.)? (short answer)

---

### Overall UI/UX Feedback

1. **Typography:** How would you rate font size and readability? (1–5)
2. **Visual design:** How would you rate the color scheme and contrast? (1–5)
3. **Consistency:** How consistent did the UI feel across pages (buttons, spacing, headings, patterns)? (1–5)
4. **Performance perception:** Did the site feel fast and responsive? (1–5)
5. **Accessibility:** How accessible did the interface feel (contrast, focus states, tap targets, readability)? (1–5)
6. **Overall impression:** How would you rate the website overall? (1–5)
7. **Top improvement:** If you could change only one thing to improve the experience, what would it be? (short answer)
8. **Bug report:** Did anything not work as expected? If yes, describe what happened and where. (short answer)

### Short description for the participants

in this evaluation, you will be asked to complete a few tasks on our website and then answer some questions about your experience.
the tasks will involve navigating through the pages, adding items to the shopping cart, and editing your profile information.
after completing the tasks, you will be asked to rate the design elements and functionalities of the website.
the evaluation should take approximately 10-15 minutes to complete.
your feedback is valuable to us and will help us improve the design of our website. thank you for participating!
